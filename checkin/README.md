# Онлайн-регистрация гостя «Парк Север»

Модуль «анкета + договор найма + подпись в один клик» по ТЗ «Модуль онлайн-чекина».

Администратор создаёт заезд и отправляет гостю персональную ссылку `https://park-sever.ru/checkin/<токен>`. Гость с телефона заполняет анкету, читает договор и подписывает его простой электронной подписью (ПЭП). Сервер сохраняет доказательства подписи, формирует PDF и присылает уведомление в Telegram.

- **Стек:** PHP 8.1+ и SQLite, без фреймворков и composer. Работает на любом российском хостинге: Reg.ru, Beget, TimeWeb.
- **PDF:** библиотека tFPDF (лежит в `lib/`), шрифт DejaVu Serif.
- **Сборка сайта:** модуль в неё не входит. Astro его не собирает, а деплой сайта его не трогает — в rsync стоит `--exclude '/checkin/'`.

## 1. Быстрый запуск на своём компьютере

Нужны только PHP и эта папка. Node, база и веб-сервер не нужны.

### 1.1. Установить PHP (один раз)

**Windows**, в PowerShell:

```powershell
winget install PHP.PHP.8.3
```

Закройте и заново откройте терминал, затем проверьте: `php -v`.

Если `winget` нет, скачайте zip «VS16 x64 Non Thread Safe» с https://windows.php.net/download, распакуйте, например, в `C:\php` и добавьте эту папку в `PATH`.

**Включить расширения.** Команда `php --ini` покажет, где лежит `php.ini`. Если файла нет, скопируйте рядом `php.ini-development` под именем `php.ini`. Откройте его и уберите `;` в начале строк:

```ini
extension_dir = "ext"
extension=curl
extension=mbstring
extension=openssl
extension=pdo_sqlite
extension=sodium
```

**macOS:** `brew install php`. **Linux:** `sudo apt install php-cli php-sqlite3 php-mbstring php-curl`. На обеих системах нужные расширения обычно включены сразу.

### 1.2. Запустить

Все команды выполняются из корня репозитория `park-sever-redesign`, в PowerShell или Git Bash:

```bash
php checkin/cli.php check                 # проверка: везде должно быть [ok]
php checkin/cli.php init мойПароль123     # создаст checkin/config.php (логин admin)
php checkin/cli.php stay                  # создаст тестовый заезд и напечатает ссылку гостя
php -S 127.0.0.1:4391 checkin/index.php   # запустит сервер; остановка — Ctrl+C
```

Откройте в браузере:

| Что | Адрес |
|---|---|
| Кабинет администратора | http://127.0.0.1:4391/checkin/admin (логин `admin`, пароль из `init`) |
| Экран гостя | ссылка, которую напечатала команда `stay` |

Чтобы посмотреть экран гостя в размере телефона, в Chrome нажмите F12, затем значок телефона (Ctrl+Shift+M).

**С телефона в той же Wi-Fi сети:** запустите сервер командой `php -S 0.0.0.0:4391 checkin/index.php` и откройте `http://<IP-компьютера>:4391/checkin/...`. IP компьютера покажет `ipconfig`. Чтобы ссылки из кабинета тоже вели на этот адрес, поставьте его в `public_url` в `checkin/config.php`.

### 1.3. Где лежат локальные данные

- База, PDF и кэш шрифтов лежат в `checkin/data/`. Файл настроек — `checkin/config.php`. Оба в `.gitignore` и в git не попадают.
- **Начать с чистого листа:** удалите `checkin/data/checkin.sqlite*` и папку `checkin/data/pdf`.
- **Новый пароль:** удалите `config.php` и снова выполните `init`. Старые PDF после этого не откроются: у нового конфига новый ключ шифрования.

## 2. Как это работает (сценарий)

1. **Администратор** в кабинете нажимает «Новый заезд» и заполняет:
   - дом;
   - заезд (по умолчанию 17:00) и выезд (по умолчанию 12:00);
   - стоимость и депозит (5 000 ₽);
   - необязательно: пометку «кто бронировал» и телефон гостя.

   В карточке заезда появляются ссылка и кнопки: WhatsApp, Telegram, ВКонтакте, «Текст для MAX» и «Скопировать». Нажатие любой из них отмечает ссылку отправленной.
2. **Гость** открывает ссылку. Вверху — карточка брони: фото дома, даты, стоимость и депозит. Дальше пять шагов:
   1. **Знакомство:** ФИО, дата рождения, телефон, email.
   2. **Паспорт:** серия, номер, дата выдачи, код подразделения, кем выдан, адрес регистрации.
   3. **Поездка:** машина для пропуска и тумблер «Со мной второй гость».
   4. **Правила фермы:** собаки, олени, кормление, огонь — это Приложение № 2, плюс одна галочка.
   5. **Договор и подпись:** сводка данных, документы в шторках (договор, опись, согласие на ПДн), галочки и золотая кнопка «Подписать договор найма».

   Кнопка «Продолжить» неактивна, пока шаг не заполнен. Пустые поля подсвечиваются без подписей. Текст ошибки появляется, только если поле заполнено неверно.
3. **После подписи** гость видит экран «Спасибо, <имя>!» и может скачать PDF. В кабинете статус меняется на «Договор подписан», в Telegram приходит уведомление.
4. **Изменить условия:** администратор правит дом, даты или сумму в карточке заезда. Если договор уже подписан, прежний PDF остаётся в архиве, а гость переподписывает договор по той же ссылке. Анкета подставится сама.
5. **Продлить проживание:** в карточке указывается новая дата выезда и доплата. Гость по той же ссылке подписывает доп. соглашение в один клик.
6. **Статусы в журнале:** «Ссылка создана», «Ссылка отправлена», «Договор подписан», «Гость проживает», «Выезд оформлен», «Отменено».

### Что проверить при локальном тесте

- [ ] Создать заезд в кабинете и скопировать ссылку.
- [ ] Пройти все пять шагов в режиме телефона. Нажать «Продолжить» на пустом шаге: подсвечиваются поля, подписей нет.
- [ ] Ввести неверный код подразделения (5 цифр) и уйти с поля: появится «Формат: 000-000».
- [ ] Открыть все три документа в шторках.
- [ ] Подписать, скачать PDF и открыть его: данные, штамп ПЭП, отдельная страница согласия.
- [ ] В кабинете: анкета гостя, блок «Подписанные документы» с IP и временем, история событий.
- [ ] Изменить сумму в карточке: гость видит «Условия обновлены» и переподписывает.
- [ ] Продлить на день: гость подписывает доп. соглашение.
- [ ] Выполнить `php checkin/cli.php verify`: «цепочка цела», «PDF совпадают».

## 3. Доказательная база подписи

| Что фиксируется | Где хранится |
|---|---|
| Дата и время с микросекундами (UTC и МСК) | БД, PDF, журнал |
| IP (+ X-Forwarded-For), User-Agent, часовой пояс, экран, язык устройства | БД, PDF |
| Ключ ПЭП — уникальная ссылка (128 бит случайности), отправленная на телефон гостя | БД, PDF (начало токена) |
| Редакция договора и **SHA-256 текста**, который видел гость | БД, PDF |
| Дословные тексты проставленных галочек | БД (в зашифрованном виде), PDF |
| **SHA-256 итогового PDF**: любая правка файла задним числом будет видна | БД, журнал |
| **Журнал событий с хэш-цепочкой**: открыл ссылку, ошибки в анкете, подписал, скачал PDF. Каждая запись содержит хэш предыдущей | БД; последний хэш уходит в Telegram как внешнее подтверждение |

Проверка: `php checkin/cli.php verify` или страница «Журнал событий» в кабинете.

**Юридическая схема.** Договор заключается в электронной форме: оферта и её акцепт (ст. 434, 438 ГК РФ). Подпись простая электронная — ПЭП (ст. 5, 6, 9 закона № 63-ФЗ). Соглашение сторон о ПЭП записано в разделе 7 самого договора. Самое слабое место — доказать, что подписал именно гость. Его закрывает SMS-код (см. раздел 7).

## 4. Защита персональных данных (152-ФЗ)

- Паспортные данные в БД и PDF на диске **зашифрованы** (libsodium, ключ хранится в `config.php`).
- На сервере БД и PDF лежат **вне папки сайта** (`data_dir`), сам сервер находится в РФ.
- Страница гостя: `noindex`, `Referrer-Policy: no-referrer` (токен не утекает на другие сайты), строгий CSP, внешних скриптов нет.
- Кабинет: пароль в виде bcrypt, 8 попыток за 15 минут, CSRF-защита, cookie `HttpOnly; SameSite=Strict`.
- Согласие на обработку ПДн — **отдельный документ с отдельной галочкой** (так требует закон с 01.09.2025).
- Telegram — иностранный сервис. Поэтому по умолчанию ФИО и госномер в уведомление **не попадают** (`telegram_pii => false`). Включать их можно только после уведомления РКН о трансграничной передаче.

## 5. Боевой запуск на Reg.ru

Сейчас на хостинге модуля нет. Там лежит только статическое демо `/checkin-demo/`.

1. **Проверить хостинг:** PHP 8.1 или выше для сайта park-sever.ru (панель Reg.ru → «Версия PHP»), включён **HTTPS**.
2. **Залить папку `checkin/`** в `…/www/park-sever.ru/checkin/`, без `config.php` и `data/`. Способы: вручную через SFTP или шагом в GitHub Actions — его можно добавить по образцу деплоя сайта, SSH-ключ там уже есть.
3. **На сервере по SSH:**
   ```bash
   cd ~/www/park-sever.ru
   php checkin/cli.php check
   php checkin/cli.php init 'надёжный-пароль'
   mkdir -p ~/checkin-data && chmod 700 ~/checkin-data
   ```
   В `checkin/config.php` исправить:
   - `public_url` → `https://park-sever.ru`;
   - `data_dir` → абсолютный путь к `~/checkin-data`, например `/var/www/u0124240/data/checkin-data`.
4. **Сохранить `encryption_key`** из `config.php` отдельно от сервера, например в менеджере паролей. **Без этого ключа договоры не расшифровать.**
5. **Telegram:**
   - создать бота у @BotFather;
   - написать ему любое сообщение;
   - узнать свой `chat_id` (например, через @userinfobot);
   - вписать `telegram_bot_token` и `telegram_chat_id` в `config.php`.
6. **Боевой тест:** создать заезд, отправить себе ссылку, подписать с телефона. Проверить PDF и уведомление. Убедиться, что в PDF стоит **ваш реальный IP**, а не адрес сервера. Если там IP хостинга, прописать его в `trusted_proxies`.
7. **Бэкап:** папку `data_dir` сохранять регулярно и хранить 5 лет.
8. **Убрать демо:** удалить `public/checkin-demo/` из репозитория.

## 6. Что заполнить до запуска

- [ ] **Договор** (`app/documents.php`). Сейчас там проект на основе оферты сайта, переписанный под найм жилого дома фермера. **Обязательно вычитать юристом.** После любой правки поднять `DOC_VERSION`.
- [ ] **Опись имущества и суммы компенсации** по каждому дому (`app/data/houses.php`). Сейчас суммы не указаны, печатается «по фактической стоимости восстановления».
- [ ] **Второй дом:** название и фото (`app/data/houses.php`, фото — в `assets/img/`).
- [ ] **ОГРНИП** — дописать в `LANDLORD` в `app/bootstrap.php`.
- [ ] **Уведомление РКН** об обработке ПДн и обновлённая политика конфиденциальности на сайте, где упомянуты паспортные данные гостей.

## 7. Можно усилить потом

- **SMS-код при подписи.** Доказывает, что ссылку открыл владелец номера. Так подписывают договоры банки и сервисы ЭП. Нужен SMS-провайдер (SMS.ru, SMSC).
- **Письмо гостю с PDF.** Сейчас гость скачивает копию сам, с экрана «Спасибо».
- **Акт сдачи дома при выезде с фото.** Без него депозит за ущерб отстоять сложнее: договор сам по себе не доказывает, кто что разбил.

```
  app/pdf.php          генерация и шифрованное хранение PDF
  app/notify.php       Telegram
  app/views/guest/     шаблоны экрана гостя (form.php — пять шагов)

```

## 9. Частые проблемы

| Симптом | Что делать |
|---|---|
| `php` не найден | PHP не в `PATH`: перезапустите терминал после установки или добавьте папку PHP в `PATH` |
| `could not find driver` или `Call to undefined function sodium_…` | Не включены `pdo_sqlite` или `sodium` в `php.ini` (см. 1.1). Проверка: `php checkin/cli.php check` |
| «Нет config.php» на странице | Выполните `php checkin/cli.php init пароль` |
| Не пускает в кабинет | Логин `admin`. Забыли пароль — удалите `config.php` и выполните `init` заново |
| «Слишком много попыток» | Подождите 15 минут или удалите `checkin/data/checkin.sqlite` (только локально) |
| Экран гостя «Ссылка недействительна» | Выезд был больше 30 дней назад или заезд отменён: создайте новый (`cli.php stay`) |
| На телефоне старый дизайн | Кэш браузера: закройте вкладку и откройте ссылку заново |
| PDF не открывается после пересоздания `config.php` | Сменился ключ шифрования. Локально удалите `data/` и начните заново |
